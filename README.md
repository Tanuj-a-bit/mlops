# Product Recommendation System with MLOps

End-to-end product recommendation system using the RetailRocket dataset
with full MLOps lifecycle (DVC, CI/CD, monitoring).

## Tools
- Python (uv)
- Pandas, Scikit-learn
- Implicit ALS
- FastAPI
- DVC
- Weights & Biases
- EvidentlyAI
- Prometheus & Grafana
